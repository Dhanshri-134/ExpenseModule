ESTIMATE CALCULATIONS

This estimate now calculates from the actual values entered in the UI.

What is included
- Labor entries
- Subcontractor entries
- Material entries
- Equipment entries
- Estimate-level overhead %
- Estimate-level profit %

What is not included in the estimate summary total
- Commission
- Direct overhead section
- Discount
- Shipping charge
- Additional / extra charges

ROW-LEVEL CALCULATIONS

1. Labor
- ST Hours = straightTimePersons * 8 * straightTimeDays
- OT Hours = overtimePersons * 10 * overtimeDays
- ST Rate = targetWage * 1.55
- OT Rate = targetWage * 2.24
- Base Total = (ST Hours * ST Rate) + (OT Hours * OT Rate)
- Row Overhead = Base Total * labor overhead %
- Row Profit = (Base Total + Row Overhead) * labor profit %
- Row Final Total = Base Total + Row Overhead + Row Profit

2. Subcontractor
- Base Amount = cost
- Workers Comp = cost * workers comp %
- Liability = cost * liability %
- Base Total = cost + workers comp + liability
- Row Overhead = Base Total * subcontractor overhead %
- Row Profit = (Base Total + Row Overhead) * subcontractor profit %
- Row Final Total = Base Total + Row Overhead + Row Profit

3. Material
- Waste Qty = quantity * (1 + waste %)
- Base Cost = Waste Qty * unit rate
- Cost With Freight = Base Cost + freight
- Tax Amount = Cost With Freight * tax %
- Base Total = Cost With Freight + Tax Amount
- Row Overhead = Base Total * material overhead %
- Row Profit = (Base Total + Row Overhead) * material profit %
- Row Final Total = Base Total + Row Overhead + Row Profit

4. Equipment
- Base Cost = quantity * rentalDays * unitRate
- Cost With Freight = Base Cost + freight
- Fuel Amount = Cost With Freight * fuel %
- Cost With Fuel = Cost With Freight + Fuel Amount
- Tax Amount = Cost With Fuel * tax %
- Base Total = Cost With Fuel + Tax Amount
- Row Overhead = Base Total * equipment overhead %
- Row Profit = (Base Total + Row Overhead) * equipment profit %
- Row Final Total = Base Total + Row Overhead + Row Profit

COST CODE TOTAL
- Cost Code Base Cost =
  labor row final totals
  + subcontractor row final totals
  + material row final totals
  + equipment row final totals

- Cost Code Overhead = Cost Code Base Cost * estimate overhead %
- Cost Code Profit = (Cost Code Base Cost + Cost Code Overhead) * estimate profit %
- Cost Code Total Price = Cost Code Base Cost + Cost Code Overhead + Cost Code Profit

ESTIMATE TOTAL
- Labor Total = sum of all labor row final totals
- Subcontractor Total = sum of all subcontractor row final totals
- Material Total = sum of all material row final totals
- Equipment Total = sum of all equipment row final totals
- Tax Total = sum of material tax amounts + equipment tax amounts

- Estimate Base Cost =
  Labor Total
  + Subcontractor Total
  + Material Total
  + Equipment Total

- Estimate Overhead = Estimate Base Cost * estimate overhead %
- Estimate Profit = (Estimate Base Cost + Estimate Overhead) * estimate profit %
- Estimate Total Price = Estimate Base Cost + Estimate Overhead + Estimate Profit

PDF TOTAL
- PDF Grand Total uses Estimate Total Price / Final Bid from estimate summary
- Customer details are hidden if no client/customer information exists

BOTTOM LINE DISPLAY
- Bottom line now shows Labor, Subcontractor, Material, Equipment, Tax, Overhead, Profit, and Total Estimate
